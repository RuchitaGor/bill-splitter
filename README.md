# Bill Splitter

A simple and user-friendly web application that helps users split a bill equally among multiple people.

## About the Project

The Bill Splitter application makes it easy to calculate how much each person needs to pay when sharing a bill. Users can enter the total bill amount and the number of people, and the application calculates the amount per person.

## Features

- Enter the total bill amount.
- Enter the number of people sharing the bill.
- Calculate the amount payable per person.
- Option to round up the amount per person.
- Simple and user-friendly interface.
- Instant calculation results.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/RuchitaGor/bill-splitter.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Enter the bill amount and number of people.

5. Click the Calculate button to see the result.
